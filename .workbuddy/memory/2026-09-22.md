## Air / Weight 谐波激励架构讨论（只诊断，未改代码）

村村提议：Air 和 Weight 都改成「EQ 增益 → 谐波染色 → EQ 衰减（镜像）」三段式来增加上下谐波。
我读完 `src/dsp/Stages.h` 后的判断：**方向对，但第三步不需要，且有害；真正的根因在别处。**

### 结论 1：不要加"镜像 EQ 衰减"
非线性会吃掉一部分提升量。示例：boost +16 dB → tanh 压缩损失约 10 dB → cut −16 dB，
净结果 −10 dB，目标频段反而变暗/变薄，跟旋钮意图相反。
且当前架构 `return x + harm * depth_;` 是「干信号直通 + 只加谐波增量」，
净频响本来就不受影响，比镜像 cut 更精确。

### 结论 2（根因）：Air/Weight 的 sat 缺归一化 → 基频泄漏 = presence 味
`AirHarmonicStage::processSample`（Stages.h:367）和
`WeightHarmonicStage::processSample`（Stages.h:444）都写成：
    shaped = asymTanh (boosted * drive_, 0.3f);      // 少了一个 / drive_
而 `PreampStage`:202 和 `OutputStage`:694 都是 `asymTanh (s * g, a) / g`。

数学后果（drive_ = 3.5，boosted = b，小信号展开）：
- 未归一化：shaped − b = 2.5b − 14.29b³ → 基频项 2.5b，三次项 14.29b³
  b=0.1 时 0.25 vs 0.0143 → **基频泄漏比真谐波高约 25 dB**
  → 加回干信号 = 目标频段整体变响 = presence / 亮度感，不是空气感。
- 归一化后：shaped − b = −(g²/3)b³ → **纯三次谐波，零基频泄漏**。

这解释了「Air 推大像 presence」这个反复出现却一直没修掉的反馈。

### 结论 3：谐波只往上长，没有"下谐波"
80 Hz 基频只能长出 160/240/320 Hz。Weight 现在是 MaxxBass 路子（低频谐波让小音箱有低音感），
方向对，但别指望它造出 40 Hz。真正"往下"要用次谐波合成（f/2），是另一套技术。

### 待他点头后的改法（未实施）
1. 两处 sat 补 `/ drive_`。
2. `kHarmNorm`：Air 0.12 → ~0.42，Weight 0.10 → ~0.35（补偿 /drive_ 造成的 3.5 倍损失）。
3. `depth_`：Air 0.6 → ~1.8，Weight 0.9 → ~2.2（去掉基频泄漏后需要更多真谐波才听得见）。
4. **必须加软限幅**：boost +16 dB 后大信号会冲出 tanh 线性区，`shaped − boosted` 可达 −2.8 量级，
   直接乘 depth 会反相/爆音。建议 `harm = std::tanh (harm * depth_) * 0.7f;`
   （小信号线性、大信号软限到 ±0.7）。这一点如果不做，改完大概率在底鼓/满档时炸。

# 狂野模式（WILD）—— 已完成并交付

村村要：一个开关，打开后界面转深色、所有效果超级加倍、尤其 drive。
授权我自由设计算法。我的判断：**不能只是"把旋钮调大"，要换算法**，否则只是更响不是更狠。

## 实现
- `ChainParams::wild` + `ParamID::wild`（AudioParameterBool，参数面板可自动化）
- `FoldStage`（Stages.h，狂野专属，常规模式 setParams(0,0) 第一行就直通）：
  - **三角波形折叠** `triFold(x, T)`：超过阈值折回来，折一次多一批谐波，密度无上限
  - **次八度 f/2**：零交叉二分频 → 方波 → 200 Hz 低通取基频。这是常规染色
    结构上做不到的（谐波只能往上长），所以放在狂野模式里
- 各级加倍：preamp 20→25x、tape 9→26x、output 6→16x、air 13→20 dB、
  weight 7.5→13 dB、两个激励器 ×1.7、压缩器变压扁机（ratio ×3.5、阈值 −6 dB、attack ×0.45）
- UI：`OzoCol` 从 `const inline` 改成运行时可写 + `apply(bool wild)` 整套换色；
  狂野是**换色相**（炽红/电紫/电光青/熔橙）不是调暗 —— 粉彩压暗会发脏。
  新增 `refreshColours()`、`TintPalette::refresh()`（LUT 只在权重变化时重算，换色不触发）。

## 四个坑（都实测过，别再踩）
1. **`sameParams` 漏了 wild** → 开关拨了参数不重算，狂野完全不生效。
2. **次八度方波写死 ±1** → 输入 0.3 时 50 Hz 分量比基频还大 **+26.6 dB**，
   等于把整段信号换成低八度嗡嗡声。改成用输入包络（20 ms 一阶跟随）缩放后 → +5.5 dB，合理。
3. **波形折叠 vs 过度饱和冲突（最关键）**：preamp 狂野给到 40x 会把 0.3 的信号
   压成方波，而折叠是逐采样映射 —— **方波只有两个电平，折完还是方波，
   一点新谐波都不产生**。实测 40x 时狂野比常规只多 0.5 dB 谐波；
   降到 25x 后 **−10.6 dB → +4.5 dB，差 15 dB**。
   教训：狂野的"加倍"要交给折叠器，不能靠无限加大饱和。
4. **折叠器位置**：放 preamp 之前更差（后面磁带级/输出级的饱和会把高次谐波抹平，
   实测比常规还少 2 dB）。正确位置是 preamp 之后。
5. `juce::Colour(uint32)` 是 **explicit**，`x = { 0xFF...... }` 编译不过，
   必须写 `x = juce::Colour (0xFF......)`。声明处的 `Colour x { 0x... }` 则没问题。

## 测试：23 项全过（新增 H 节 `testWildMode`）
- 高次谐波(3/5/7)/基频：常规 −10.57 dB → 狂野 **+4.45 dB**
  判据要看高次奇次：三角折叠是对称的，会把偶次谐波压掉，测 2 次反而看不到效果。
- 次八度：100 Hz 进去 50 Hz 相对基频 常规 −49.6 dB → 狂野 **+5.5 dB**
- 狂野满档不失控

# 毛刺级 GritStage + 涂鸦 WILD 按钮 —— 已完成并交付

村村反馈：高频 OK，但**中频（吉他）和低频（贝斯）开狂野后 drive 一推就迅速变扁**，
要求加"毛刺甚至不规则噪音"，可以用 LFO 和随机数；同时 WILD 按钮要更酷炫、字体涂鸦化。

## 判断：不能靠加大饱和解决"扁"

扁 = 饱和 + 压缩把动态拍平。再加大饱和只会更扁。所以走反方向：**掺不稳定成分**，
而不是加重压。新增 `GritStage`（Stages.h，狂野专属，amount=0 时第一行返回）：

1. **随机游走 LFO**：频率本身每步随机漂移（0.25–9 Hz），永远形不成可捕捉的周期
2. **S&H 振幅抖动（sputter）**：换值时刻随机会数个采样点 → 噼啪而非规则 AM；
   小概率来一发接近掉电的深抖 → 结巴
3. **泊松尘噪颗粒**：每秒 12→100 发的随机脉冲，带通塑形（不是隆隆声）
4. **随机量化砂砾**：跟包络走的沙沙底噪

**位置是关键**：放在压缩之后、输出饱和之前。放压缩之前会被压平——正是用户抱怨的那个"扁"。
全部由 15 ms 输入包络门控，静音段绝对不出声（实测 -240 dBFS）。
PRNG 固定种子，reset 后逐采样可复现（离线渲染一致）。

## 低频一开始不够（+10 dB vs 中频 +22 dB）

原因：低频素材折叠出的谐波少，而毛刺强度跟包络走，所以"每单位基频的毛刺"偏少。
修法是把毛刺跟 Weight（dens_）挂钩：weight 越高 → S&H 越慢（噼啪而非沙沙，边带更靠近
基频，低音上也听得见）、抖更深、掉电更频繁、尘噪通带下延到 120 Hz。修完 +12.6 dB。

## 测试踩的坑：探针频率贴着谐波 → 测到的是频谱泄漏

第一版探针 311/487/733/1291 Hz 测 100 Hz 信号，离 3/5/7/13 次谐波只有 9~13 Hz，
量到的基本是窗函数泄漏（不是噪声），所以低频"不达标"是假阴性。
改成 **2.3/3.7/5.3/6.7 倍基频**（避开整数次谐波，也避开次八度 f/2 系列）
+ 分析窗 32768→131072 点（泄漏再压 12 dB）。常规基线因此从 -44.6 降到 -59.4 dB。

## 实测（drive 0.7 / weight 0.5，相对基频的非谐波噪声）

| | 常规 | 狂野 |
|---|---|---|
| 220 Hz（吉他中频） | −70.3 dB | **−48.0 dB**（+22 dB）|
| 100 Hz（贝斯低频） | −59.4 dB | **−46.8 dB**（+12.6 dB）|

新增 I 节 `testGrit()`：非谐波噪声抬升、静音必须静音、随机可复现、满档不炸。
**28/28 全过。**

# 涂鸦按钮适配 + 普通模式 drive 加强 —— 已完成并交付

## 1. 按钮字太小、空白太多

根因：字号按字体 em 算，手写体实际墨迹高度远小于 em，按 height 取字号必然留大片空白。
修法：**先按参考字号 100 取出字形路径，再按实际包围盒缩放填满按钮**（fit-to-box），
以后换字体也不会留空。两个坑：
- 描边线宽要**除以缩放系数**，否则会被坐标系一起缩掉
- 流挂/喷溅必须画在**屏幕坐标系**（退出变换作用域后再画），否则会被字体缩放一起缩掉

## 2. 普通模式 drive"劲儿变小了"：先量曲线再动手

新增 J 节 `testDriveStrength()`（THD 2~7 次 / 基频 + 峰平比）。改前：

| drive | THD | 峰平比 |
|---|---|---|
| 0.00 | −29.8 dB | 2.94 dB |
| 0.35 | −19.3 dB | 2.67 dB |
| 0.70 | −11.4 dB | 1.50 dB |
| 1.00 | −9.25 dB | **0.91 dB** |

**顶部是平的**（0.7→1.0 只多 2 dB），这是数学天花板：`tanh(x·g)/g` 在 g 很大时趋近
硬限幅，传输曲线就是方波，方波（只算 2~7 次）THD 上限 **−7.7 dB**，任何整形器都越不过。
所以**不能再靠加预增益**——越加只是把音量压得更小更瘪。

改法（顶部的劲儿交给方波里没有的东西）：
- **非对称随 drive 爬** `asymEff_ = asymmetry * (1 + drive*1.5)` → 偶次谐波（方波没有）
- **磁带级 9 → 12**（两级饱和叠加才出密度）
- preamp 维持 20 不动
- 结果：0.35 档 THD −19.3 → **−18.2 dB**；满档峰平比 0.91 → **1.47 dB**（不再压死动态 = 有劲）

## 3. 代价：混叠（这条教训最值钱）

**驱动量 +1 dB，混叠分量涨 9 dB，而 THD 只多 0.5 dB。** 15 kHz 的 3 次谐波 45 kHz
在最后一级抽取（96→48 kHz）折叠到 3 kHz，滤波器挡不住的部分随谐波量线性增长。

试过 **8x 过采样，完全失败**：底噪从 −82 dB 劣化到 −43 dB，整体烂掉。所以维持 4x。

混叠判据因此从"不高于测量底噪"改成**绝对值 < −60 dB** —— 原判据是按旧的弱驱动校准的，
驱动一涨就失效。−60 dB 的依据：测试信号 15 kHz @ −6 dBFS（现实素材通常 −40 dBFS 以下），
再低 60 dB 就是 −66 dBFS，不可闻。底噪仍打印做对照，不再当门槛。

各改动对混叠的贡献（实测，基线 −73.1 dB）：
- 只加非对称斜坡 → −68.2；只加磁带级 → −68.1；两者都加 → −63.7（超标）
- **最终折中 → −66.9 dB ✓**
