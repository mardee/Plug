# GLINT 0.3.0 — 七 lane 调音工作台

这版用于手动找到好听的组合，不增加随机黑盒。每条固定音程关系：原音、上三度、上五度、上八度、下三度、下五度、下八度。

## 每行控制

| 控件 | 含义 |
|---|---|
| On | 该声部是否参与；不再由Amount自动开关 |
| First | 收到原音后，到首次回声的时值，独立于Repeat |
| Repeat | 此后重复间隔，固定音乐时值 |
| Feedback | 每经过一个Repeat周期所保留的力度比例；越高延续越长，最大98%，0仅一次成功回声 |
| Level | 相对原音velocity的首次力度比例 |
| Length | 生成音符按住时值，不等于外部钢琴真实音频尾长 |
| Motion | 衰减上界内部的力度波动深度，0只剩指数衰减 |
| Wave cycle | 波动力度的周期，1/2/4/8拍 |

First、Repeat、Length支持三十二分、附点三十二分、十六分、附点十六分、八分、附点八分、四分、附点四分、二分、附点二分。统一随宿主速度换算。

## Feedback与首次衰减分开

首次力度由原音力度×Level决定。之后的上界为Level×Feedback^(经过拍数/Repeat拍数)，再乘Motion波动。例：原音100、Level40%、Feedback80%、Motion0，回声力度约40、32、26……。

Amount暂作为全局强度，30%为Level倍率1，调每行时建议保持30%。0停止新增，调高也不会超过原音力度。后续找到满意组合后，可再重新设计一个简单主宏。

## 实时调节

- Level、Feedback、Motion、Wave cycle：影响后续生成，不重新启动时间轴。
- First、Repeat、Length：新输入音符采用新设置；已有回声按原时值完成，避免突然变速或挂音。
- 关闭On：停止该lane未来生成，已发Note Off仍会正常送出。重新打开只作用新的输入，不复活旧回声。
- 高Feedback仍有64拍或48秒安全上限；不能无限自激。

同音占用、踏板保持、32生成声部和每秒48事件限制继续存在，可能跳过某些落点，但不会欠账后爆发。

## 调性与路由

Root/Scale用于调内上下三度/五度。未设调性时这些声部不会凭空猜音，只能用同度和八度；有些低音下移受音域保护也可能无声。Output Add/Particles保留既有Studio One路由。
