# GLINT 0.1.3 — 方向与同步律动

## 两个新控制

**Direction** 控制相对所选演奏音符的音区，不是左右声像，也不是严格单调的琶音排序：

- **Up**：原音区及向上八度；高Amount时Bloom/Pulse可上两八度。
- **Down**：原音区及下八度。下移结果低于MIDI48时不强行降，不能为制造低音而越界或改音级。
- **Both**：上下都有，保留声部对答、短方向轮廓与低音保护。

**Rate** 控制宿主同步的基础节拍：

- **Free**：原0.1.2按速度尺度变化的自由动机；Bloom保留轻微时间偏移，不宣称落在严格网格。
- **1/8**：八分音符。
- **1/16**：十六分音符。
- **1/8 D**：附点八分。
- **1/8 T**：八分三连音。

新实例默认 **Both + 1/8**。已有工程或v1状态迁移为 **Both + Free**，保留原节奏习惯。

## 律动如何工作

同步时不是每格必定发音，而是在选定网格上组织短动机、重音、弱音和留白。Rate决定网格，Amount控制出现概率/强度/延续，不偷换基础速度。Character保留Echo回应、Bloom短簇和Pulse脉冲的差异。

所有同步模式（包括Bloom）不使用自由时间抖动，落点跟随宿主BPM和有效PPQ位置。第一颗粒子不会提前于输入击键。改变BPM或跳转时遵循已有清理规则；宿主停播、PPQ冻结时使用内部连续时钟。

方向是“往哪个音区展开”。Up不保证后一颗音一定高于前一颗；Down也不是把原始MIDI旋律倒序。没有新增音阶推断、音频反向或左右声像处理。

## 兼容

保留既有插件身份、前三个参数的ID/顺序及MIDI乐器路由。追加 `direction`、`rate` 两个可自动化参数；状态版本升为2，仍读取旧v1并填入Both/Free。坏状态、未知版本、重复或缺失参数拒绝读取。

旧版本插件不承诺读取v2状态；升级前备份旧工程。运行中改变Direction/Rate只改变后续候选，不强切已有音符，必要Note Off仍保留。
