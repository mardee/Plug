# GLINT 0.1.4 — 鲜明性格、八度范围、混合节奏

## 控制

- **Character** 仍是 Echo / Bloom / Pulse，但在同步模式下也使用不同节奏组织、音长及重音轮廓，避免不同模式因量化到同一网格而趋同。
- **Octaves** 新增 Auto / 1 Oct / 2 Oct / 3 Oct。Auto延续旧音区策略；显式范围与Amount分开，3 Oct允许相对演奏音符最多36半音的八度展开。
- **Direction** 继续决定Up/Down/Both。Octaves只是最大范围，不是每个音都强制移到最远处。向下仍保护MIDI48以下的新低音，原演奏不动。
- **Rhythm** 新增 Single / Mixed。Single沿用Rate指定的单一基础节拍；Mixed在同一序列中组合不同音符时值，并保留宿主速度同步。

## 混合不是纯随机漂移

Mixed以1/12拍公用细网格组织3、4、6、9等tick时长，对应十六分、八分三连音、八分、附点八分，配合少量整倍留白。不同Character有不同组合，不是把多条无限反馈线叠起来。

Rate在Mixed下表示整组节奏的快慢尺度：1/8为标准速度；1/16为半时长；1/8 D为1.5倍时长；1/8 T为2/3时长。Free+Mixed仍按宿主速度（缺失时回退内部速度）运行，使用标准混合尺度；要保留旧自由时间变化请选Free+Single。

Rate现有五个选项的索引和宿主归一化映射不变。没有把Mixed直接塞进Rate的选项末尾，以免影响旧自动化映射。

## 三种性格的目标区别

- **Echo**：较规则的回声骨架，清晰回应，较紧的音区偏好和衰减重音。
- **Bloom**：短簇、长留白、较宽音区，音长更长且有柔和起伏。
- **Pulse**：明显切分、短促音长、较大的重音/弱音对比。

最终听感取决于外部音源是否响应力度和Note Off。测试只能检查事件结构，不能替代你的钢琴试听。

## 状态与安全

追加 `octaves`、`rhythm` 两个可自动化参数，旧五个参数ID/顺序不变。状态版本3严格保存七参数，同时读取v1/v2：旧状态补Auto+Single，v1同时补Both+Free。

仍保留固定声部预算、24次On/秒、8秒活动和2秒按键硬上限、同音仲裁、踏板及停止/跳转清理。参数变化仅改变后续生成；停止播放仍会结束自有按键。

旧版不能保证读取v3状态，升级前保留工程副本。新增八度仍只使用演奏音符的整数八度，不自动添加新和弦音级，不包含反向音频效果。

## 0.1.4 验证结果

- 核心69/69、UBSan69/69通过，新增显式1/2/3八度、低Amount仍可展开、Mixed时值/网格/变速/停止和自动化、各模式五种block划分一致性测试。
- 四组CTest最终均通过：核心、Processor、VST3回录、AU回录。最初AU旧夹具要求默认Bloom的一次和弦必须生成超过3个音，因新版更长留白失败；改为显式Mixed＋1/8＋2 Oct验证新增参数后通过。未降低Note On/Off平衡或时间因果断言。
- 真实VST3回录验证三种性格下Up/Down的3 Oct极值，以及Mixed拍位；旧v1状态在新引擎中恢复后与手工设置等效。
- v3七参数保存/恢复、非法参数拒绝、v1/v2迁移Auto＋Single及一旋钮六选择控件绑定通过。
- Mixed固定测试素材下，Echo/Bloom/Pulse的gate中位数分别约145/288/36 ms，力度标准差约16.9/12.9/23.7。只是特定48kHz测试素材的客观统计，不是所有演奏的固定表现，更不是听感验收。
- 560×410界面预览已检查，文本与控件没有遮挡或越界。Studio One路由封装保持0.1.1以来的形式，助手未实际试听本版。

建议从 **Bloom / Both / 2 Oct / Mixed / 1/8 / Amount 50%** 开始，保持其他设置切换Character比较三种性格。
