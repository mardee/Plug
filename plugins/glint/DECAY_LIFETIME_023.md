# GLINT 0.2.3 衰减与生命周期说明

## 1. 衰减终止与生命周期
- **取消次数上限**：取消每 lane 最多 3 次候选的限制。
- **阈值自然终止**：以非线性衰减的力度上界降至源力度的3.5%作为结束条件，不在某次波谷较低时提前结束。该阈值不是音频响度或分贝。
- **硬安全上限**：32拍或24秒作为底层兜底，普通速度下通常先达到衰减阈值。极慢速度、持续输入导致的云容量替换或宿主停止，仍可能提前结束未发回声；不保证任意场景都只由阈值结束。

## 2. 力度包络与衰减行为
- **时间基准**：decay 从计划首次拍位开始计算生命周期。
- **动态曲线**：首次回声有显著减幅，随后在指数衰减包络内波动。
- **阻断恢复**：blocked / 静音恢复后继续跟随既定衰减进度，不会重新恢复到第一下的强度。

## 3. 碰撞、静音与踏板保护
- **碰撞处理**：无声碰撞不计入实际播放，不重置衰减进度，也不会在解禁后积压补发。
- **踏板保护**：保持同键踏板保护机制，密集或冲突时会相应降低实际触发频次。

## 4. 声部角色与调性
- **固定音程角色**：每条 lane 维持固定音程的七个角色分配。
- **未设调性行为**：未设置调性时只出同音或八度。
- **Amount 控制**：Amount 用于控制声部参与度和织体丰富度，不再设定硬性次数。

## 5. 保持不变的设计
- 原本音 velocity 比例与附点真实音符间隔保持不变。
- UI 交互与 state v5 数据结构保持不变。

## 6. 精简验证结果
- 11项smoke通过，包含默认lane持续超过3次、同度被占用后继续衰减恢复、未发声不计入实际On和尾部Note Off配对。
- 四组CTest（核心、真实VST3、Processor、AU）通过；未运行full/UBSan大矩阵。
- 120BPM、D5短音、源力度100、C大调、Amount30%的实际VST3回录：三度14次、五度13次、八度8次；最后On约8.875/7.1875/6.75秒。此为一组固定输入，不是固定次数或所有音源的响度保证。
- 合并七条声部可形成密集交织，短簇与留白检查按单条固定音高进行；全局最小间隔和原音保护仍检查，没有把合并流误当一条琶音。
- 未由助手在DAW中试听；MIDI事件数量和尾部验证不替代实际音乐性评价。
